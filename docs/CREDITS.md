# 积分预付（人工确认充值）

## 规则

- **1 积分 = ¥0.01**
- 生成前扣积分；提交 RunPod 失败自动退回
- `PAYMENT_MODE=manual_qr`：个人收款码 + 备注码 + 管理员确认
- RunPod 单价默认 **24GB $0.69/hr**

## 充值流程

选套餐 → 展示收款码与备注码 → 用户转账并申报 → 管理员确认入账

## 页面

- `/` 文生图（需登录）
- `/credits` 充值
- `/login` 登录
- `/admin/recharges` 待确认队列（管理员）

## 风控

1. 预付费：必须先充值
2. 倍数 ≥ 2
3. RunPod Daily Spend Limit
4. 同用户未完成充值单最多 2 笔；订单 30 分钟过期
